## Stage 0: the network split

1. **The test command is `node --test server/*.test.mjs`, not `node --test server/`.** In Node 24 a bare folder argument is resolved like a module import, so `node --test server/` runs `server/index.mjs` itself and starts the real server on port 4747 against the real data (observed tonight). The README and `server/package.json` (`npm test`) carry the glob. Each test now starts its own throwaway server on a copy of the data (`server/_scratch.mjs`), so the suite never touches `data/`.
2. **The calendar test was rewritten to run against the filled November plan.** It had been written before the import and assumed 2 November's Reel slot was open; it now takes the first two open Monday Reel slots.
3. **The link token was generated once into `data/settings.json`** (48 hex characters) and is shown read-only in Settings, Link, with a copy button. There is no button to rotate it: rotating would break Network silently, and a founder who needs a new one edits the JSON and restarts. Palak may want a "rotate" button later.
4. **`GET /api/link/pieces` reads `status=published` as `posted` or `measured`** (Studio's own words for a piece that is out), and also accepts `approved`, `posted` and `measured`. `title` is the YouTube title where there is one, else the hook; `channel` is the first target account's platform; `url` and `publishedAt` come from the measure block, so they are empty until a piece is posted and measured. `solutionId` is passed through and is empty today, because no piece carries one yet.
5. **The WhatsApp one-to-one line stays on the event** (`templates.whatsapp`, written by the greetingTemplates operation) and goes out over the link as `wording.whatsapp`, as SPLIT-AND-HOSTING.md section 2 specifies. It is no longer shown in Studio's Greetings tab, so marketing staff see the Status and LinkedIn wording only. If the founder wants to edit that line, it is in Network.
6. **The `touch-batch` slot kind was removed** from the calendar's kind list; nothing ever generated one and it belongs to Network.
7. **Hosting in ARCHITECTURE.md section 10 now points at SPLIT-AND-HOSTING.md section 3** (Vercel, Google Sheets, Drive), replacing the Supabase paragraph, because that is tonight's decision.
8. **Pronouns.** Palak's pronouns are they/them. Text written tonight uses them. Existing copy in PLAN.html and the design document that says "her" or "she" was left as written where it was not otherwise being edited, to keep the diff to the split; it is listed under "Only Palak can decide" in the final report as a wording pass.
9. **The Studio server is stopped with a cwd-aware kill**, not `pkill -f "server/index.mjs"`, because the Network tool's server on port 4748 runs from the same command line and `pkill` would have stopped it too.

19. **The storyline count is a text proxy**: a piece "names a tool" when any public text contains a Solutions name longer than three letters; it "says system without naming one" when the text contains "system" and names none. It is a pointer to the review pass, not a verdict.
20. **`data/settings.json` and `data/log.json` are no longer served under `/data/`**; they hold the link token, PIN hashes and who did what. The other collections stay readable there for inspection.
